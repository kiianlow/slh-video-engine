# Motion Graphics Skill

## Purpose

Convert a simple prompt into a polished faceless explainer video.

Default output:
- 1080x1920 vertical
- TikTok / Reels / Shorts format
- Embedded captions
- Smooth motion graphics
- Professional typography
- Narration
- Background music
- MP4 export

## Creative Principles

Always prioritize:

1. Clarity
2. Visual hierarchy
3. Motion quality
4. Mobile readability
5. Caption readability

Avoid:

- Template aesthetics
- Excessive effects
- Overlapping text
- Tiny typography
- Random animations
- Visual clutter

## Workflow

1. Analyze prompt
2. Create creative brief
3. Generate storyboard
4. Generate narration
5. Create scene plan
6. Generate visuals
7. Generate captions
8. Generate audio
9. Render
10. QA
11. Export

## Default Video Structure

Hook
Problem
Explanation
Key Insight
Takeaway
CTA

## Visual Style Engine

Automatically choose a style based on topic:

- Apple keynote
- Linear
- Stripe
- Notion
- Duolingo
- Editorial magazine
- Modern infographic

Default: Linear + Apple hybrid.

## Typography Rules

- Large readable text
- Maximum 12 words per screen
- One key message per scene
- Strong contrast
- Consistent spacing

Preferred fonts:

- Inter
- Geist
- SF Pro
- General Sans

## Motion Rules

Use:

- Smooth easing
- Spring motion
- Scale transitions
- Fade transitions
- Position interpolation
- Staggered reveals

Avoid:

- Excessive spins
- Flashing effects
- Chaotic movement

## Caption Rules

Captions are mandatory.

Style:

- TikTok-inspired
- Active word highlighting
- Dynamic emphasis
- Embedded hero words

Rules:

- 90% standard caption rail
- 10% hero moments
- One hero word at a time
- Keep captions inside safe zones

Example:

Narration:
"Most people think productivity is about working harder."

Display:
working harder

as the emphasized hero phrase.

## Scene Design

Each scene should contain:

- One primary message
- One visual focus
- One motion direction

Maximum:
- 3 visual layers
- 2 accent colors
- 1 focal point

## Visual Elements

Preferred:

- Diagrams
- Flowcharts
- Timelines
- Data visualization
- Animated icons
- UI mockups
- Typography compositions

Avoid overuse of stock footage.

## Audio

Generate:

- Voiceover
- Background music
- Sound effects

Mixing:

- Voice priority
- Music under narration
- SFX subtle

## Editing Mode

If a project exists:

Treat new prompts as edits.

Examples:

- Make scene 2 longer
- Change colors to black and gold
- Replace music
- Make captions larger
- Add stronger hook
- Convert to 60 seconds

Preserve unaffected scenes.

## Quality Assurance

Before render verify:

- No clipping
- No overlap
- Readable typography
- Smooth motion
- Accurate captions
- Audio balance
- Consistent colors
- Mobile readability

## Export Targets

Vertical:
- 1080x1920

Landscape:
- 1920x1080

Square:
- 1080x1080

Formats:
- MP4
- WebM
- MOV

## Golden Rule

The result should feel like a professionally designed faceless explainer,
not a slideshow and not a generic template.
