# Real Estate Motion Design System

## Purpose

This design system defines the visual language for all real estate educational videos, reels, social content, explainers, carousels, and motion graphics.

The goal is to create premium, mobile-first property content that feels modern, trustworthy, educational, and visually consistent.

---

# Design Priority Order

Always follow this priority order:

1. Reference layout style from existing project examples
2. Use Fluent UI Emoji assets for icons
3. Use uploaded project assets
4. Generate new assets only if no suitable Fluent UI Emoji asset exists

Never generate generic infographic icons when a Fluent UI Emoji equivalent exists.

---

# Core Design Philosophy

The content should feel like:

- Premium real estate education
- Instagram carousel content
- Luxury property marketing
- Clean editorial design
- Mobile-first storytelling

The content should NOT feel like:

- Corporate PowerPoint slides
- Generic infographics
- Canva templates
- Stock vector illustrations
- SaaS explainer videos

---

# Visual Hierarchy

## Rule 1: Typography Is The Hero

Typography should carry most of the communication.

## Rule 2: One Icon Per Screen

Preferred:
- 1 primary icon

Acceptable:
- 2 related icons

Avoid:
- Multiple icon clusters
- Busy infographic layouts
- Complex diagrams

Maximum:
3 primary visual elements per frame.

## Rule 3: Icons Support The Message

Icons are visual reinforcement.

Icons are NOT the main focus.

---

# Icon System

## Primary Asset Library

Always use Fluent UI Emoji assets first.

Required characteristics:

- Colourful
- Rounded
- 3D appearance
- Soft gradients
- Friendly
- Modern

## Never Use

- Outline icons
- Flat vector icons
- Monochrome icons
- Thin-line illustrations
- Corporate infographic assets
- Generic stock SVG icons

---

# Typography

## Font

Nunito Sans

## Headline

Weight: 900 Black

## Body Copy

Weight: 300 Light

---

# Colour System

## Background

Preferred:

- Warm cream
- Soft ivory
- Light beige

Avoid:

- Bright gradients
- Loud colours
- Dark dramatic backgrounds

---

# Motion Guidelines

Allowed:

- Fade
- Scale
- Slide
- Pop

Duration:

300ms–800ms

Easing:

Smooth ease-in-out with subtle overshoot.

---

# Success Criteria

Every visual output must:

- Feel like premium real estate education content
- Follow the provided reference layouts
- Use Fluent UI Emoji assets whenever possible
- Keep typography as the primary focus
- Use icons as supporting elements
- Maintain a warm editorial aesthetic
- Be optimised for mobile viewing
- Use subtle, professional motion
- Remain visually consistent across the entire project
