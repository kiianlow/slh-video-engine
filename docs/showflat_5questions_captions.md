## RedNote / 小红书

标题：去新加坡看 showflat 前，一定要问的5个问题 📋

很多人第一次看 showflat，进去就被漂亮的装修吸引了。其实有几个关键问题，很多买家都忘记问 👇

1️⃣ 实际可用面积有多少？（不是 strata 面积，注意 void 空间）
2️⃣ 这个单位在几楼？PSF 是多少？（楼层和朝向都会影响）
3️⃣ 发展商是谁？过去的项目质量怎么样？
4️⃣ TOP 日期大概是什么时候？（新盘通常要等 3 到 5 年）
5️⃣ 有没有延期付款方案（DPS）？
