# Typography System

Primary font family: Nunito Sans

## Font Source

Use the uploaded variable font file:

- fonts/NunitoSans-VariableFont_YTLC,opsz,wdth,wght.ttf

## Font Weights

### Headlines and Titles

- Font: Nunito Sans
- Weight: 900 (Black)
- Line height: 1.1
- Letter spacing: 0% to +2%
- Use: Titles, headers, hooks, callouts, lower thirds

### Body Text

- Font: Nunito Sans
- Weight: 300 (Light)
- Line height: 1.4
- Letter spacing: 0%
- Use: Captions, descriptions, supporting text, subtitles

## Visual Principles

- Mobile-first readability
- Clear hierarchy
- High contrast
- Clean layouts
- Minimal styling

## Instructions for Claude

When creating any visual asset, storyboard, thumbnail, social media graphic, HTML, CSS, or video overlay:

1. Use Nunito Sans weight 900 for headlines and titles.
2. Use Nunito Sans weight 300 for all supporting text.
3. Do not substitute another font unless explicitly requested.
4. Prioritize readability on mobile screens.
