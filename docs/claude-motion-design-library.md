# Motion Design Library for Claude

## Purpose

This document defines the approved motion vocabulary for real estate explainer videos, reels, educational content, social media animations, and motion graphics.

Claude should use these motion primitives instead of inventing random animation styles.

---

# Motion Philosophy

Motion should support communication.

Animation should:
- Guide attention
- Reinforce hierarchy
- Improve comprehension
- Add energy without distraction

Avoid excessive movement.

---

# Entrance Motions

## Fade In

Duration: 400ms

Opacity:
0% → 100%

Use:
- Captions
- Notes
- Supporting text

---

## Fade Up

Duration: 500ms

Y:
+30px → 0px

Opacity:
0% → 100%

Use:
- Headlines
- Cards
- Section titles

---

## Slide Left

# Usage Rules

1. Motion must support the message.
2. Use subtle motion by default.
3. Reserve dramatic motion for key moments.
4. Avoid combining more than 2 major motion types simultaneously.
5. Headlines should primarily use Fade Up or Slide motions.
6. Icons may use Pop, Bounce, Spin, or Morph motions.
7. Use premium motions sparingly for luxury feel.
8. Maintain visual consistency across all scenes.
