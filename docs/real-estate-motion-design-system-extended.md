# Real Estate Motion Design System (Extended)

## Purpose
Premium, mobile-first real estate educational content using editorial layouts and Fluent UI Emoji assets.

## Asset Priority
1. Uploaded Fluent UI Emoji assets
2. Uploaded project assets
3. Newly generated assets matching Fluent UI Emoji style

Never generate a replacement if a Fluent UI Emoji asset already exists.

---

# Visual Philosophy

Typography is the hero.
Icons are supporting elements.
Layouts should feel like luxury real estate education, not infographics.

---

# Typography

Font: Nunito Sans

Headline:
- Black 900
- Large
- Dominant

Body:
- Light 300
- Clean and readable

---

# Layout Structure

QUESTION 01 / 04

[Icon]

HEADLINE

[Supporting Note]

KEYWORD

Rules:
- One primary icon per screen
- Large typography
- Generous spacing
- Mobile-first 9:16 layout

---

# Icon Style

Required:
- Colourful
- Rounded
- 3D
- Soft gradients
- Friendly
- Modern

Avoid:
- Outline icons
- Flat vector icons
- Thin-line icons
- Corporate infographic icons
